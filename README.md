## 3. API-ийн тухай

Энэхүү лабораторийн ажлаар хичээлд бүртгүүлэх API-г Postman болон Newman ашиглан туршсан.

API сервер нь `http://localhost:3000` хаяг дээр ажиллана.

Үндсэн үйлдлүүд:

| HTTP Method | Endpoint | Зориулалт |
|---|---|---|
| PUT | `/students/:id` | Оюутан үүсгэх эсвэл мэдээллийг шинэчлэх |
| PUT | `/courses/:id` | Хичээл үүсгэх эсвэл мэдээллийг шинэчлэх |
| GET | `/courses/:id` | Хичээлийн мэдээлэл авах |
| POST | `/registrations` | Хичээлд бүртгүүлэх |
| GET | `/registrations` | Бүртгэлүүдийн жагсаалт авах |

## 5. Тестийн спецификац

|---|---|---:|---|
| TC-01 | Идэвхтэй оюутан амжилттай бүртгүүлэх | 201 | `OK` |

| TC-06 | Оюутан болон хичээл байхгүй | 200 | `ERROR_NO_STUDENT` |
| TC-07 | Идэвхгүй оюутан болон байхгүй хичээл | 200 | `ERROR_INACTIVE_STUDENT` |

## 6. Newman тестийн үр дүн

### 6.1. PASS туршилт

PASS туршилтаар зөв Collection ашиглан API-ийн хүсэлтүүд болон assertion-уудыг ажиллуулсан.

| Үзүүлэлт | Үр дүн |
|---|---:|
| Нийт хүсэлт | 27 |
| Амжилтгүй хүсэлт | 0 |
| Нийт assertion | 42 |
| Амжилтгүй assertion | 0 |
| Newman exit code | 0 |
| Төлөв | PASS |

### 6.2. FAIL туршилт

FAIL туршилтаар `lab05-collection-fail.json` файлын нэг oracle-ийг зориудаар буруу тохируулсан. Амжилттай бүртгүүлэх үед API `201 Created` буцаадаг боловч тест `200` статус хүлээж байгаа тул уг assertion амжилтгүй болох ёстой.

| Үзүүлэлт | Үр дүн |
|---|---|
| Туршилтын файл | `lab05-collection-fail.json` |
| Буруу oracle | Хүлээгдэх статусыг `200` болгосон |
| Бодит статус | `201 Created` |
| Хүлээгдэх үр дүн | Assertion алдаа илрүүлэх |
| Newman exit code | Ажиллуулсны дараа бөглөнө |
| Төлөв | FAIL |

**Анхаарах зүйл:** FAIL туршилтыг сервер ажиллаж байх үед гүйцэтгэнэ. Сервер унтарсан үед гарсан `ECONNREFUSED` алдаа нь зориуд буруу oracle-ийг илрүүлсэн үр дүн биш юм.

### 6.3. DOWN туршилт

DOWN туршилтаар API серверийг зогсоож, Newman Collection-ийг дахин ажиллуулсан.

| Үзүүлэлт | Үр дүн |
|---|---|
| API сервер | Зогсоосон |
| Хүлээгдэх алдаа | `ECONNREFUSED` |
| Хүлээгдэх төлөв | DOWN |
| Newman exit code | Ажиллуулсны дараа |

## 7. Үр дүнгийн файлууд

Тестийн гаралтыг `results/` хавтсанд хадгалав.

| Файл | Зориулалт |
|---|---|
| `results/newman-pass.txt` | Амжилттай тестийн гаралт |
| `results/newman-fail.txt` | Fail тестийн гаралт |

### Newman ажиллуулах командууд

PASS:

```powershell
$output = newman run lab05-collection.json 2>&1
$code = $LASTEXITCODE
$output | Out-File results/newman-pass.txt -Encoding utf8
"Exit code: $code"
```

FAIL:

```powershell
$output = newman run lab05-collection-fail.json 2>&1
$code = $LASTEXITCODE
$output | Out-File results/newman-fail.txt -Encoding utf8
"Exit code: $code"
```
